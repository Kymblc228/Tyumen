# База данных библиотечной системы

Учебный проект по проектированию и созданию реляционной базы данных для сети библиотек на языке SQL (SQLite).

## 📌 О проекте
В рамках проекта была спроектирована база данных, которая позволяет хранить и обрабатывать информацию о библиотеках, книгах, библиотекарях и читателях, а также отслеживать выдачу книг.

## 📊 Структура БД
База данных состоит из 5 связанных таблиц:
*   **Libraries** (Библиотеки) — филиалы, адреса, часы работы.
*   **Librarians** (Библиотекари) — сотрудники, привязанные к конкретным библиотекам.
*   **Readers** (Читатели) — ФИО, пол, возраст, район проживания.
*   **Books** (Книги) — каталог книг (автор, жанр, привязка к библиотеке).
*   **Loans** (Выдачи) — связующая таблица, фиксирующая, кто какую книгу взял.

## 📁 Структура репозитория
*   `docs/` — документация (паспорт проекта, ER-диаграмма, описание аналитики).
*   `sql/` — SQL-скрипты (создание структуры, наполнение данными, аналитические запросы).
*   `data/` — исходные данные в формате CSV.
*   `excel/` — исходный Excel-файл с данными.
*   `presentation/` — материалы для защиты проекта.

## 🚀 Как развернуть базу данных
1. Откройте любой клиент для работы с SQLite (например, DB Browser for SQLite или онлайн-компилятор).
2. Выполните скрипт `sql/01_schema.sql` для создания таблиц и связей.
3. Выполните скрипт `sql/02_data.sql` для наполнения базы тестовыми данными.
4. Для проверки аналитики выполните запросы из файла `sql/03_queries.sql`.
